
Transform Generator (TG)
Developer: Gordon Myers

The AAVSO Transform Generator (TG) is software for calculating photometric transformation coefficients from observations of standard stars. It accepts photometry from sources including AIP4WIN, MaxIm, and VPhot, allows users to examine and exclude problematic measurements, and can save, compare, and average transformation sets. The final coefficients can be exported for use with the AAVSO TransformApplier.

Installation: TG has three installation options. The release page,  https://github.com/AAVSO/TransformGenerator/releases , will have zip files for each.

    For a Windows installation with a single executable version of TG:   TG 6.11 single executable Windows Installation files.zip
    For a Windows installation requiring installation of the full Anaconda suite:   TG 6.11 files for Full Anaconda Windows Installation files.zip
    For a Mac installation:  TG 6.11 Mac Installation Files
