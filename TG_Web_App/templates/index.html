A browser home for TG 6.11

Use this workflow for Johnson–Cousins UBVRI transformation coefficients. Calculations run in Python using SciPy ordinary least squares. The browser handles file selection, plotting, and saved sets.

1. Choose standards

Fetch M67, NGC7790, or coordinates from AAVSO VSP, or upload an exported VSP JSON catalog. Reference CSV columns are id,label,ra,dec,U,B,V,R,I; magnitudes are case sensitive and coordinates use degrees. Missing bands should be blank. Original Henden numeric IDs for M67 and NGC7790 are mapped to the AUIDs in your source.

2. Import measurements

TG/AIP4WIN: semicolon, comma, or tab separated, with a Filt;b;v;… header and star IDs in the first column; repeated filter columns are averaged. MaxIm: one export beginning Timestamp (JD),Filter and columns ending : Instrument Magnitude (Centroid). VPhot: tab or semicolon separated exports with Filter:, JD: and the Star header. Only active stars strictly above the SNR threshold are included; ambiguous labels must match reference magnitude and B−V. CSV: id,u,b,v,r,i,jd, with repeated measurements averaged by star and band. Zero and −1000 magnitude sentinels are ignored as in TG.

3. Inspect the fit

Color coefficients such as Tbv use the reciprocal of the instrumental-versus-standard color slope. Magnitude coefficients such as Tv_bv use the direct slope. At least three stars and a nonzero color range are required. Single-filter magnitude coefficients are supported when the reference catalog supplies the required standard colors. Click plot points or table checkboxes to adjust each fit. The 3σ action uses residual scatter from the currently included fit and performs one clipping pass.

Reciprocal errors retain the TG 6.11 convention σm / [m(m − σm)], reported as a nonnegative magnitude. This differs from first-order propagation σm/m². The shaded plot band represents ±3 residual σ, not a confidence interval. Catalog magnitude errors and instrumental errors are not fit weights.

4. Save and average

Save sets by telescope and Julian date; reopen them to continue refining. Select sets from the same telescope to average. INI exports retain the original Setup, Coefficients, Error, and R Squared Values sections. JSON backups contain measurements and exclusions; CSV/INI contain coefficients. Import the original Photometry_Transform_Config_Data.txt to migrate telescope names; use Import TG history for the original transform_values.ptgp coefficient archive.

Deployment & privacy

The default server is for local use at 127.0.0.1. Uploaded observations are processed in memory and not written by the server. Saved sets live in this browser's local storage and are shared by tabs at the same origin. This edition has no accounts or access control; add those before shared public hosting. AAVSO catalog retrieval requires internet access; uploaded catalogs and the example work offline.

Validation scope

Automated checks cover coefficient math, reciprocal uncertainties, exclusion/refitting, averaging, importer fixtures, and API exports. The supplied source did not include real observation exports, so check each importer against your own files and compare a known TG result before scientific production use.

AAVSO API documentation: www.aavso.org/api-vsp
